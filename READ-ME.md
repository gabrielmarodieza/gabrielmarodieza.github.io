## Maintaining the site
Edit portfolio-content.json for career entries, verified tool descriptions, the planned project roadmap and future completed credentials. Then, from this folder, run:

    node source/build-site.mjs .

Node.js is required only for rebuilding; there are no npm dependencies. source/sample-results.json holds the original calculated sample preview. Layout and static narrative live in source/build-site.mjs, styles.css and script.js. Rebuilding replaces index.html and favicon.svg. The opening evidence panels and structured-data skills are maintained in the builder and must be kept consistent with any future factual changes.

credentials is currently empty. Add only legitimately completed credentials with status, name, issuer, date and an HTTPS verification url. Only status completed with all these fields renders. This rendering rule is not a substitute for verifying the actual credential. Future credentials and completed independent projects should be added only with real evidence; do not simply relabel a planned item.

The six planned studies follow hiring relevance: bank reconciliation, AP aging, advanced Excel analysis, QBO workflow, month-end close simulation and payroll reconciliation. QBO/Xero learning is not a current skill claim. Completed case studies need their own description, artifact, authorship and evidence review.
